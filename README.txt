GYANSETU DIGITAL — DEPLOYMENT GUIDE
1) Extract this ZIP. Keep the folder structure intact.
2) Upload all files and the articles folder to the ROOT of a new GitHub repository.
3) On Vercel choose Add New > Project > Import Git Repository > Deploy.
4) No build command or framework preset is needed for this static HTML website.
5) After deployment, replace relative canonical/sitemap URLs with your actual domain URLs.
6) IMPORTANT: In contact.html replace the placeholder email with your real working email.
7) Add more original, well-researched articles before applying for AdSense. Review every page, correct errors, add author/editor details and keep the site updated.
8) Submit the real sitemap URL in Google Search Console after connecting and verifying your domain.
9) Apply for AdSense only after the website is complete and complies with current Google Publisher Policies.

This ZIP is a static starter website. It does not guarantee Google indexing, AdSense approval, traffic or income. The sample articles are starting content; expand them with original expertise and sources. Do not publish copied or thin content. No analytics, login, database or automatic AI writing is included.
